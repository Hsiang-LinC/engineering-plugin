## Development Harness

Before changing this plugin, read `docs/harness/index.md` and follow its routing.

Hard rules:
1. Work state lives in the tracker; read `docs/harness/tracker.md` first.
2. Code, skill, contract, or documentation changes require a work item before
   the first edit. Reading and discussion do not.
3. Completion requires verification, independent acceptance, a tracker update,
   and durable documentation when facts change.
4. Routing lives only in `docs/harness/index.md`.
